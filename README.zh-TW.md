# Green Futures Wheel（綠色未來輪）

**語言：** [English](README.md) · **中文** · [ไทย](README.th.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Español](README.es.md)

一個免費、單頁式的**未來輪（Futures Wheel, Glenn, 1971）**工作坊工具——一群人可以在同一個房間裡即時共同建構一張未來輪，每個人用自己的語言、用自己手邊的裝置。不需安裝、不需帳號、不需編譯。

## 特色

- **單一 HTML 檔案。** 不用 npm 安裝、不用編譯。開啟它，或用伺服器提供它，就能用。
- **即時多人協作編輯。** 連到同一個房間的所有人都會立即看到彼此的變動（底層採用 Yjs）。
- **可切換介面語言。** 中文、英文、泰文、阿拉伯文、法文、俄文、西班牙文——從下拉選單直接切換，不用重新整理。每個人自己選的語言只影響自己看到的畫面，不會改變別人看到的內容。
- **個人顯示翻譯。** 另外，你也可以把「別人打的文字」機器翻譯成你自己想看的語言，只改你自己看到的畫面，不會動到大家共同的內容。
- **可選的 GenAI 協助。** 可以向 Gemini、ChatGPT、Claude、Grok，或本機的 LM Studio 模型要幾個下一圈的靈感建議。這些建議只是討論的起點——不會自動被採納，隨時可以編輯或刪除。
- **匯出功能。** 整張未來輪或單一分支，都能直接匯出成可編輯的 PowerPoint 檔，也支援 PNG 圖片匯出與 JSON 匯入匯出。
- **教室模式。** 講師的一台電腦就能把頁面提供給同一個 Wi-Fi 下的所有裝置——區域網路的部分不需要連上網際網路。

## 快速開始

**方式 A — 直接開啟（單人使用）。**
雙擊 `index.html`。單人使用沒問題，但即時協作在 `file://` 底下無法運作：瀏覽器會擋掉即時共編需要的 WebSocket 連線。

**方式 B — 啟動本機伺服器（協作時需要）。**
- Windows：雙擊 `Startup.bat`。它會啟動一個內建的小型 HTTP 伺服器，把可分享的連結複製到剪貼簿，並自動用瀏覽器打開。
- 任何裝有 Node.js 的系統：在這個資料夾裡執行 `npx serve .`，再打開它印出來的網址。

不管用哪種方式，要讓多台裝置共用同一張未來輪，就在每台裝置上開啟**同一個網址**、帶著**同一個 `?room=XXXX`**。

## 執行工作坊／教室場次

1.（可選）把 `workshop-room.txt` 改成你想要的四位數房號，預設是 `2026`。
2. 在講師的電腦上執行 `Startup.bat`。
3. 把它印出來的區網網址（類似 `http://192.168.x.x:3456/?room=XXXX`）分享給同一個 Wi-Fi 下的所有人。
4. 整個場次期間都讓那個黑色視窗保持開啟——關掉它，所有人的連線都會中斷。

## 需要注意的事

- **共同房間預設是公開的。** 沒有另外設金鑰的情況下，這個工具會連到免費的公開中繼伺服器（`demos.yjs.dev` 與一個架在 Glitch 上的中繼站）來同步房間內容。任何知道或猜到你四位數房號的人，都能加入並編輯那個房間——沒有密碼保護。不要把不希望陌生人看到或改動的內容放進共同房間。如果需要封閉場次，可以用 `start-collab-server.ps1`（或 `.cmd`）自己架一個中繼站——它會在 `ws://localhost:4455` 監聽，只有同一個區域網路裡的人能連上。
- **`file://` 會關掉協作功能。** 用雙擊方式直接打開 `index.html`，即時同步會整個失效。只要有兩人以上要一起編輯，就要用本機伺服器（見「快速開始」）。
- **GenAI 金鑰只會留在你的瀏覽器裡。** 如果你為 Gemini、ChatGPT、Claude 或 Grok 填了 API Key，它只會存在那個瀏覽器的 `localStorage` 裡，也只會送到那家廠商自己的 API——絕不會送到這個專案架設的任何伺服器。LM Studio 完全不需要金鑰；只要在 LM Studio 自己的伺服器設定裡打開「Enable CORS」，一切都留在你自己的電腦上。
- **大部分功能離線也能用。** 核心的未來輪功能——繪製、編輯、排列、顏色、形狀——都已經打包在本機（vis-network 就放在 `vendor/` 裡），不需要連網。只有少數幾個可選功能會連到網路：即時協作、個人顯示翻譯（用的是 MyMemory 的免費 API）、GenAI 靈感建議，以及 PowerPoint 匯出。
- **預設的未來輪只是空白起始範本，不是完成的範例。**「核心議題」「直接影響1～3」，加上一組間接／連鎖影響的提示，全部都是等著你輸入內容的——在你編輯之前，它們只是提示文字，不是真正的內容。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個應用程式本體。 |
| `vendor/` | 打包好的 vis-network 函式庫（讓應用程式能離線運作）。 |
| `Startup.bat` / `workshop-server.ps1` | 一鍵啟動的本機網頁伺服器，供教室／工作坊使用。 |
| `workshop-room.txt` | `Startup.bat` 使用的四位數房號。 |
| `start-collab-server.ps1` / `.cmd` | 可選：自己架一個本機協作中繼站，取代公開的示範伺服器。 |
| `bump-version.ps1` | 給維護者用的工具：更新應用程式裡顯示的版本號。 |
