# Green Futures Wheel

**Языки:** [English](README.md) · [中文](README.zh-TW.md) · [ไทย](README.th.md) · [العربية](README.ar.md) · [Français](README.fr.md) · **Русский** · [Español](README.es.md)

Бесплатный однностраничный инструмент для проведения воркшопов **«Колесо будущего»** (Futures Wheel, Glenn, 1971) — группа людей может вместе строить одно колесо в реальном времени, каждый на своём языке, на любом устройстве. Без установки, без учётной записи, без сборки.

> **Это проект в постоянной разработке**, а не готовый продукт — он продолжает меняться по мере использования в реальных воркшопах. Если что-то непонятно, не работает или могло бы быть лучше, пожалуйста, [откройте issue](https://github.com/oiioandy/GreenFuturesWheel/issues) или начните обсуждение. Любое предложение искренне приветствуется и очень ценится.

## Основные возможности

- **Один HTML-файл.** Не нужна установка npm, не нужна сборка. Откройте его или разместите на сервере — и всё готово.
- **Совместное редактирование в реальном времени.** Все, кто подключён к одной комнате, мгновенно видят каждое изменение (на основе Yjs).
- **Переключаемый язык интерфейса.** Китайский, английский, тайский, арабский, французский, русский и испанский — выбирайте из выпадающего списка без перезагрузки. Выбор каждого человека индивидуален и никогда не меняет то, что видят другие.
- **Персональный перевод отображения.** Отдельно вы можете машинно перевести *только то, что видите вы сами* — текст других участников — на выбранный вами язык, без изменения общего содержимого, которое видят все.
- **Опциональная помощь GenAI.** Запросите у Gemini, ChatGPT, Claude, Grok или локальной модели LM Studio несколько идей для следующего круга. Это лишь отправные точки для обсуждения — они никогда не принимаются автоматически, их всегда можно отредактировать или удалить.
- **Экспорт.** Всё колесо или одна ветвь — прямо в редактируемый файл PowerPoint, а также экспорт в PNG и импорт/экспорт JSON.
- **Режим для класса.** Один компьютер преподавателя может раздавать страницу всем устройствам в той же сети Wi-Fi — для локальной сети интернет не требуется.

## Быстрый старт

**Вариант А — просто открыть (один пользователь).**
Дважды щёлкните `index.html`. В одиночку это работает отлично, но совместная работа в реальном времени не работает через `file://`: браузеры блокируют WebSocket-соединение, необходимое для живого совместного редактирования.

**Вариант Б — запустить локальный сервер (нужен для совместной работы).**
- Windows: дважды щёлкните `Startup.bat`. Он запускает небольшой встроенный HTTP-сервер, копирует ссылку для отправки в буфер обмена и открывает её в браузере.
- Любая система с установленным Node.js: выполните `npx serve .` в этой папке, затем откройте выведенный адрес.

В любом случае откройте один и тот же адрес — с одним и тем же `?room=XXXX` — на каждом устройстве, которое должно работать с одним колесом.

## Проведение воркшопа / занятия в классе

1. (Необязательно) Измените `workshop-room.txt` на выбранный вами 4-значный номер комнаты. По умолчанию — `2026`.
2. На компьютере преподавателя запустите `Startup.bat`.
3. Отправьте выведенный адрес локальной сети (что-то вроде `http://192.168.x.x:3456/?room=XXXX`) всем в той же сети Wi-Fi.
4. Оставьте это окно консоли открытым на всё время занятия — его закрытие отключит всех от сервера.

## На что обратить внимание

- **Общие комнаты по умолчанию публичны.** Без настроенного ключа приложение подключается к бесплатным публичным релейным серверам (`demos.yjs.dev` и релею на Glitch) для синхронизации комнат. Любой, кто знает или угадает ваш 4-значный номер комнаты, может присоединиться и редактировать её — пароля нет. Не помещайте в общую комнату то, что не хотели бы показать или дать изменить незнакомцу. Для закрытой сессии запустите собственный релей с помощью `start-collab-server.ps1` (или `.cmd`) — он слушает на `ws://localhost:4455` и работает только для людей в вашей локальной сети.
- **`file://` отключает совместную работу.** Открытие `index.html` двойным щелчком полностью отключает синхронизацию в реальном времени. Используйте локальный сервер (см. Быстрый старт), если более одного человека должны редактировать вместе.
- **Ключи GenAI никогда не покидают ваш браузер.** Если вы добавите API-ключ для Gemini, ChatGPT, Claude или Grok, он будет храниться только в `localStorage` этого браузера и отправляться только в API этого провайдера — никогда на какой-либо сервер, управляемый этим проектом. LM Studio не требует ключа вообще; просто включите «Enable CORS» в настройках сервера самого LM Studio, и всё останется на вашем компьютере.
- **Большая часть приложения работает полностью офлайн.** Основное колесо — рисование, редактирование, расположение, цвета, формы — упаковано локально (vis-network находится в `vendor/`) и не требует подключения к интернету. Только несколько опциональных функций обращаются к интернету: совместная работа в реальном времени, персональный перевод отображения (бесплатный API MyMemory), предложения GenAI и экспорт в PowerPoint.
- **Колесо по умолчанию — это пустой стартовый шаблон, а не готовый пример.** «Core Topic», «Direct Impact 1–3» и один плейсхолдер для косвенного/цепного влияния — все они предназначены для того, чтобы вы их заполнили; это подсказки, а не настоящий контент, пока вы их не отредактируете.

## Обзор файлов

| Файл | Назначение |
| --- | --- |
| `index.html` | Всё приложение целиком. |
| `vendor/` | Встроенная библиотека vis-network (чтобы приложение могло работать офлайн). |
| `Startup.bat` / `workshop-server.ps1` | Локальный веб-сервер в один клик для использования в классе/воркшопе. |
| `workshop-room.txt` | 4-значный номер комнаты, который использует `Startup.bat`. |
| `start-collab-server.ps1` / `.cmd` | Опционально: запустить собственный локальный релей для совместной работы вместо публичных демо-серверов. |
| `bump-version.ps1` | Инструмент для поддержки проекта: увеличивает номер версии, показываемый в приложении. |
