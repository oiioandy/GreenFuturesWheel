# Green Futures Wheel

**ภาษา:** [English](README.md) · [中文](README.zh-TW.md) · **ไทย** · [العربية](README.ar.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Español](README.es.md)

เครื่องมือหน้าเดียวฟรีสำหรับจัดเวิร์กชอป **Futures Wheel** (Glenn, 1971) — กลุ่มคนสามารถสร้างวงล้ออนาคตร่วมกันแบบเรียลไทม์ แต่ละคนใช้ภาษาของตัวเอง บนอุปกรณ์ที่ตัวเองมี ไม่ต้องติดตั้ง ไม่ต้องมีบัญชี ไม่ต้อง build

> **นี่คือผลงานที่ยังพัฒนาอยู่ตลอด** ไม่ใช่ผลิตภัณฑ์ที่เสร็จสมบูรณ์ — มันจะเปลี่ยนแปลงต่อไปตามการใช้งานจริงในเวิร์กชอป หากมีส่วนใดที่สับสน ใช้งานไม่ได้ หรือคิดว่าน่าจะทำให้ดีขึ้นได้ ยินดีให้ [เปิด issue](https://github.com/oiioandy/oiioFuturesWheel/issues) หรือเริ่มการสนทนา ข้อเสนอแนะทุกอย่างเป็นที่ยินดีและซาบซึ้งใจอย่างยิ่ง

## จุดเด่น

- **ไฟล์ HTML เดียว** ไม่ต้องติดตั้ง npm ไม่ต้อง build เปิดไฟล์หรือรันเซิร์ฟเวอร์ก็ใช้ได้เลย
- **แก้ไขพร้อมกันแบบเรียลไทม์** ทุกคนที่เชื่อมต่อห้องเดียวกันจะเห็นการเปลี่ยนแปลงทันที (ใช้ Yjs)
- **สลับภาษาหน้าจอได้** จีน, อังกฤษ, ไทย, อาหรับ, ฝรั่งเศส, รัสเซีย, สเปน — เลือกจากดรอปดาวน์ ไม่ต้องรีโหลด การเลือกภาษาของแต่ละคนเป็นของตัวเอง ไม่กระทบสิ่งที่คนอื่นเห็น
- **แปลเฉพาะหน้าจอของตัวเอง** แยกต่างหาก คุณสามารถแปลข้อความของคนอื่นเป็นภาษาที่คุณต้องการดู โดยไม่แก้ไขเนื้อหาที่ทุกคนเห็นร่วมกัน
- **ผู้ช่วย GenAI (ไม่บังคับ)** ขอไอเดียรอบต่อไปจาก Gemini, ChatGPT, Claude, Grok หรือโมเดล LM Studio ในเครื่อง เป็นแค่จุดเริ่มต้นสำหรับการพูดคุย — ไม่ถูกใส่เข้าไปโดยอัตโนมัติ แก้ไขหรือลบได้เสมอ
- **ส่งออกได้** ทั้งวงล้อหรือกิ่งเดียว เป็นไฟล์ PowerPoint ที่แก้ไขได้ พร้อมส่งออกเป็น PNG และนำเข้า/ส่งออก JSON
- **โหมดห้องเรียน** เครื่องผู้สอนเครื่องเดียวเปิดหน้านี้ให้ทุกอุปกรณ์ใน Wi-Fi เดียวกันได้ — ส่วนที่อยู่ในเครือข่ายภายในไม่ต้องใช้อินเทอร์เน็ต

## เริ่มต้นใช้งาน

**วิธีที่ 1 — เปิดตรงๆ (ใช้คนเดียว)**
ดับเบิลคลิก `index.html` ใช้คนเดียวได้ปกติ แต่การทำงานร่วมกันแบบเรียลไทม์ใช้งานผ่าน `file://` ไม่ได้ เพราะเบราว์เซอร์จะบล็อกการเชื่อมต่อ WebSocket ที่จำเป็นสำหรับการแก้ไขร่วมกัน

**วิธีที่ 2 — รันเซิร์ฟเวอร์ในเครื่อง (จำเป็นสำหรับการทำงานร่วมกัน)**
- Windows: ดับเบิลคลิก `Startup.bat` มันจะรันเซิร์ฟเวอร์ HTTP เล็กๆ ในตัว คัดลอกลิงก์ที่แชร์ได้ไปที่คลิปบอร์ด และเปิดในเบราว์เซอร์ให้เอง
- ระบบใดก็ได้ที่มี Node.js: รัน `npx serve .` ในโฟลเดอร์นี้ แล้วเปิด URL ที่แสดงออกมา

ไม่ว่าจะวิธีไหน ให้เปิด URL เดียวกัน — พร้อม `?room=XXXX` เดียวกัน — บนทุกอุปกรณ์ที่ต้องการใช้วงล้อร่วมกัน

## การจัดเวิร์กชอป / ห้องเรียน

1. (ไม่บังคับ) แก้ไข `workshop-room.txt` ให้เป็นเลขห้อง 4 หลักที่ต้องการ ค่าเริ่มต้นคือ `2026`
2. บนเครื่องผู้สอน รัน `Startup.bat`
3. แชร์ URL ในเครือข่ายภายในที่มันแสดงออกมา (เช่น `http://192.168.x.x:3456/?room=XXXX`) ให้ทุกคนใน Wi-Fi เดียวกัน
4. เปิดหน้าต่างคอนโซลนั้นไว้ตลอดช่วงเวิร์กชอป — ถ้าปิดจะตัดการเชื่อมต่อของทุกคน

## สิ่งที่ต้องระวัง

- **ห้องที่ใช้ร่วมกันเปิดเป็นสาธารณะโดยค่าเริ่มต้น** เมื่อไม่ได้ตั้งคีย์ไว้ แอปนี้จะเชื่อมต่อกับเซิร์ฟเวอร์รีเลย์สาธารณะฟรี (`demos.yjs.dev` และรีเลย์ที่โฮสต์บน Glitch) เพื่อซิงค์ห้อง ใครก็ตามที่รู้หรือเดาเลขห้อง 4 หลักของคุณได้ก็สามารถเข้าและแก้ไขได้ — ไม่มีรหัสผ่าน อย่าใส่สิ่งที่ไม่อยากให้คนแปลกหน้าเห็นหรือแก้ไขลงในห้องที่ใช้ร่วมกัน สำหรับเซสชันแบบปิด ให้รันรีเลย์ของคุณเองด้วย `start-collab-server.ps1` (หรือ `.cmd`) — มันฟังที่ `ws://localhost:4455` และใช้ได้เฉพาะคนในเครือข่ายภายในเดียวกัน
- **`file://` ปิดการทำงานร่วมกัน** การเปิด `index.html` ด้วยการดับเบิลคลิกจะปิดการซิงค์แบบเรียลไทม์ทั้งหมด ใช้เซิร์ฟเวอร์ในเครื่อง (ดู เริ่มต้นใช้งาน) เมื่อมีคนมากกว่าหนึ่งคนต้องแก้ไขร่วมกัน
- **คีย์ GenAI ไม่ออกจากเบราว์เซอร์ของคุณเลย** ถ้าคุณเพิ่ม API key สำหรับ Gemini, ChatGPT, Claude หรือ Grok มันจะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น และส่งไปที่ API ของผู้ให้บริการนั้นเท่านั้น — ไม่เคยส่งไปยังเซิร์ฟเวอร์ใดๆ ที่โปรเจกต์นี้รันอยู่ LM Studio ไม่ต้องใช้คีย์เลย เพียงเปิด "Enable CORS" ในการตั้งค่าเซิร์ฟเวอร์ของ LM Studio เอง ทุกอย่างจะอยู่ในเครื่องของคุณ
- **ส่วนใหญ่ของแอปทำงานแบบออฟไลน์ได้เต็มรูปแบบ** วงล้อหลัก — การวาด แก้ไข จัดวาง สี รูปทรง — ถูกรวมไว้ในเครื่องแล้ว (vis-network อยู่ใน `vendor/`) ไม่ต้องใช้อินเทอร์เน็ต มีเพียงไม่กี่ฟีเจอร์ที่ไม่บังคับซึ่งต้องต่ออินเทอร์เน็ต: การทำงานร่วมกันแบบเรียลไทม์ การแปลเฉพาะหน้าจอของตัวเอง (ใช้ API ฟรีของ MyMemory) ไอเดียจาก GenAI และการส่งออก PowerPoint
- **วงล้อเริ่มต้นเป็นแค่แม่แบบเปล่าเริ่มต้น ไม่ใช่ตัวอย่างที่เสร็จแล้ว** "Core Topic", "Direct Impact 1–3" และ placeholder ผลกระทบทางอ้อม/ลูกโซ่อีกหนึ่งจุด ทั้งหมดนี้รอให้คุณพิมพ์ทับ — เป็นแค่คำแนะนำ ไม่ใช่เนื้อหาจริง จนกว่าคุณจะแก้ไขมัน

## ไฟล์โดยสรุป

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | แอปทั้งหมด |
| `vendor/` | ไลบรารี vis-network ที่รวมมาด้วย (เพื่อให้แอปทำงานออฟไลน์ได้) |
| `Startup.bat` / `workshop-server.ps1` | เซิร์ฟเวอร์เว็บในเครื่องแบบคลิกเดียวสำหรับห้องเรียน/เวิร์กชอป |
| `workshop-room.txt` | เลขห้อง 4 หลักที่ `Startup.bat` ใช้ |
| `start-collab-server.ps1` / `.cmd` | ไม่บังคับ: รันรีเลย์การทำงานร่วมกันของคุณเองแทนเซิร์ฟเวอร์สาธารณะ |
| `bump-version.ps1` | เครื่องมือสำหรับผู้ดูแล: เพิ่มเลขเวอร์ชันที่แสดงในแอป |
